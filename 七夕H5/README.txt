七夕 H5 电子相册
================

本地查看
--------
直接双击 index.html 即可打开。无需安装依赖，也不需要联网。

个性化署名
----------
用文本编辑器打开 app.js，修改文件开头的两项：

to: "老婆"
from: "爱你的我"

部署前检查
----------
1. 整个“七夕H5”目录一起上传，不能只上传 index.html。
2. 上传后用手机和微信内置浏览器各打开一次。
3. 家庭照片属于隐私内容，尽量使用临时链接；节日后可以删除部署。

免费静态部署平台
----------------
1. Cloudflare Pages
   综合推荐。支持 Git 仓库和静态目录部署，免费层通常足够个人相册使用。

2. Netlify Drop
   最省时间。可在网页中直接拖入整个文件夹生成链接，适合今晚快速上线。

3. Vercel
   适合把目录放进 GitHub 私有仓库后部署，后续修改和重新发布方便。

4. GitHub Pages
   完全静态、长期免费，但公开仓库会暴露家庭照片；使用前务必注意仓库可见性。

5. 飞书妙搭 HTML 托管
   适合已有飞书账号的场景。发布后需要确认访问范围；若分享给飞书组织外的人，必须先验证对方能否打开。

国内微信环境提示
----------------
海外免费平台在不同网络下的速度可能不一致。正式发送前，请务必用妻子的手机网络实际打开一次。若只需当面展示，也可以不部署，直接在手机浏览器打开本地文件。
